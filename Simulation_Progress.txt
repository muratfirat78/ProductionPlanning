Problem: Scheduled pending events disappear and never come to consideration.
Solution: 
Weekend jump makes a time leap in simtime. The events that are to be suspended at the time when just last shift finishes are not considered due to this. 
So, events are moved forward and the ones they need handling, they are explicitly moved to pending, from scheduled. 
(Scheduled pending event is placed in EventQueue at certain time such that at that time it is handled. An event in pending list of EventQueue is continuously checked for handling)  
 

30/07/2026: (Murat)
Problem: Machine Loading misses items to move from the input. 
Solution: 
Machine setup is triggered by Trainer Unloading and Machine Unloading. 
When there is already a Machine Setup generated, later Machine Unloading also triggers MS event and unnecessary MS event is created.
This happens in OutSourced machine, since we do not register there the pendingevent of input buffer. 
The reason is that the items convenient for lastly generated MS are not selected/reserved.

So Select Item decision is just made during the event creation, moved from handle. 
Moreover, a property for the items defined: reservedevent. Now, event generation looks for unreserved items, not just items.
